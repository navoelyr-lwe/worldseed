# P8 — Dünya host'u model kartları

Bu dizin, `04-DUNYA-VE-CEVRE.md` ve `10-SES-KALICILIK-TEKRAR.md` uyarınca kalıcı
ve çok ölçekli dünya (P8) model kartlarını içerir. Kartlar; kimlik/sürüm, temsil
edilen süreç, ölçek, durum değişkenleri, denklem/algoritma, varsayımlar, parametre
kaynağı, sayısal yöntem, doğrulama planı, kabul eşikleri ve kanıt düzeyini
kaydeder.

| Kart | Kapsam | Kanıt düzeyi |
|---|---|---|
| `MODEL-KARTI-DUNYA-HOSTU.md` | Bölge streaming, seviye ataması, boşalt/yükle durum korunumu, journal, checkpoint, replay | D2 (determinizm, bozuk kayıt ve uzun koşu testleri geçti) |

İlgili toplam popülasyon modeli kartı `docs/life/MODEL-KARTI-POPULASYON.md`
içindedir (P8, FAR/MID bölge ölçeği).
