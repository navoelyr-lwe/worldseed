# P9 — Sinematik yönetmen model kartları

Bu dizin, `09-SINEMATIK-YONETMEN.md` uyarınca P9 gözlemci katmanının model
kartlarını içerir. Kartlar; kimlik/sürüm, temsil edilen süreç, ölçek, durum
değişkenleri, denklem/algoritma, varsayımlar, parametre kaynağı, sayısal yöntem,
doğrulama planı, kabul eşikleri ve kanıt düzeyini kaydeder.

| Kart | Kapsam | Kanıt düzeyi |
|---|---|---|
| `MODEL-KARTI-YONETMEN.md` | Olay-tabanlı yönetmen: öncelik, çekim planlama, sınırlı kamera, occlusion | D2 (determinizm, sınır ve davranış testleri geçti) |

Ses kartı `docs/audio/MODEL-KARTI-SES-MANZARASI.md` içindedir. Yönetmen dünyanın
otoritesi değildir; yalnız simülasyonun gerçekten ürettiği olay akışını tüketir.
